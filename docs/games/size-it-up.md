# Size It Up

https://magnitudle.com/size-it-up

A game where you guess at the relative size of two items in five rounds.

## Game instructions

How to play Size It Up
Match real-world scale using only the visual reference.

ReferenceDrag to moveYour estimate
You are matching scale - the reference measurement stays hidden while you play.

01
Compare
Use the smaller blue object as your fixed real-world reference. Its size does not change.

02
Move and resize
Drag the red silhouette to move it. On mobile, pinch with two fingers to resize it; you can also drag a corner handle. Zoom out on the board whenever you need more room for a larger estimate.

03
Lock it in
Submit your estimate to reveal the true scale and earn up to 100 points for the round.

Tip: Start with the dimension marked by the dotted guide, then compare the objects proportionally.

Size It Up FAQ

How is Size It Up scored?
+
A closer size estimate earns more points. You can score up to 100 points in each of the five rounds and up to 500 points overall.
